# Skimmer Data Center

A proposed guided learning application for spreadsheet skills and analysis of skimmer flight data.

**Status: Brainstorming.** No working application, Google Sheet connection, or implementation roadmap is included yet.

Start with the [Non-Binding Concept Notes](docs/CONCEPT-NOTES.md), recorded September 27, 2026. They preserve the discussion for a later roadmap conversation; they are not an approved specification or feature commitment.

The intended planning sequence is concept notes, a focused roadmap conversation, concrete issues, and implementation PRs.

Companion project: [Mean Machine](https://github.com/AbbyUsesAIThatCodes/MeanMachine), focused on understanding the arithmetic mean through equal sharing. The projects are separate so each can be developed and tested independently.
